Goron GTS — Procédure de déploiement labo (A à Z)
Version {{VERSION}}

Objectif
--------
Sur un PC Windows de test, tout installer dans l'ordre : WSL, Docker,
PostgreSQL 18 vierge, Goron GTS, fichier Admin, première connexion.

On ne récupère pas une base existante. Le métier tourne dans Docker
(conteneur goron-pg18). Identifiants ci-dessous = laboratoire uniquement.

Copier ce dossier en local (jamais depuis un partage réseau).


Contenu de ce pack
------------------
  00-LIRE-EN-PREMIER.txt     ce guide
  installer\                 installateur Windows (voie conseillée)
  folder\                    Goron GTS.exe + resources
  portable\                  exe unique + data\templates (modèles Word)
  outils_labo\               menu labo (démarrer PG, logs, reset, dump)
                             + schema.sql (reset sans le dépôt source)
  outils_prod\               console production (relance PG, dumps hors appli)


══════════════════════════════════════
  1. Windows
══════════════════════════════════════
Windows 10/11 à jour. Compte autorisé à installer des programmes.
Le port 5432 doit être libre (pas d'autre PostgreSQL Windows déjà lancé).


══════════════════════════════════════
  2. Installer WSL 2
══════════════════════════════════════
Ouvrir PowerShell en administrateur, coller :

  wsl --install

Redémarrer Windows si Windows le demande.
Après reboot, terminer l'éventuelle installation Ubuntu (compte Linux
proposé par WSL : on peut l'ignorer ensuite, Docker s'en sert).

Vérifier (PowerShell normal) :

  wsl --status

Doit indiquer WSL 2. Si wsl.exe est introuvable, relancer `wsl --install`
en administrateur.


══════════════════════════════════════
  3. Installer Docker Desktop
══════════════════════════════════════
Télécharger : https://www.docker.com/products/docker-desktop/

Installer en cochant l'option **Use WSL 2 instead of Hyper-V**.
Redémarrer si l'installateur le demande.

Lancer Docker Desktop. Attendre en bas à gauche :
  Engine running
(30 à 90 secondes au premier lancement.)

Vérifier (PowerShell) :

  docker version
  docker info

Si « docker n'est pas reconnu » : fermer le terminal, en ouvrir un nouveau,
ou redémarrer la session Windows.


══════════════════════════════════════
  4. Fichier Admin (obligatoire)
══════════════════════════════════════
Créer le dossier s'il n'existe pas, puis le fichier (Bloc-notes) :

  %APPDATA%\goron-gts\data\acces_admin.env

Une seule ligne, 8 caractères minimum, sans espace autour du = :

  GTS_ADMIN_MASTER_CODE=un-code-de-test-de-8-caracteres

C'est le mot de passe de connexion « Admin » (version installée et npm run
dev). S'il existe aussi %APPDATA%\goron-gts\gts-admin.enc, c'est lui qui prime.

Noter le code : Goron GTS ne l'affiche jamais.


══════════════════════════════════════
  5. Créer PostgreSQL labo (une seule fois)
══════════════════════════════════════
Docker Desktop doit afficher Engine running. PowerShell :

  docker run -d --name goron-pg18 --restart unless-stopped `
    -e POSTGRES_DB=goron_gts `
    -e POSTGRES_USER=goron_gts_app `
    -e POSTGRES_PASSWORD=dev_app_secret `
    -e TZ=Europe/Paris `
    -p 5432:5432 `
    -v goron_gts:/var/lib/postgresql `
    postgres:18

La première fois, l'image postgres:18 se télécharge (plusieurs minutes).
Contrôle :

  docker ps --filter name=goron-pg18

Le conteneur doit être Up. Si le nom goron-pg18 existe déjà, passer à
l'étape 6 (ou section « Repartir à zéro »).

Au quotidien ensuite (pas besoin du docker run) :
  double-clic  outils_labo\Lancer-Menu-Labo.bat
  touche 1 = démarrer Docker + conteneur
  touche 5 = état
  touche 9 = tester la connexion


══════════════════════════════════════
  6. Installer Goron GTS
══════════════════════════════════════
Double-clic sur l'exe dans installer\ (options par défaut).
Lancer l'application via le raccourci Windows.

Autres voies du pack (copie locale obligatoire) :
  folder\Goron GTS.exe
  portable\Goron GTS {{VERSION}}.exe


══════════════════════════════════════
  7. Écran « Initialisation GTS »
══════════════════════════════════════
Si l'écran n'apparaît pas, PostgreSQL est déjà configuré sur ce poste
(Paramètres → Gestion Base de données).

Saisir exactement :

  Hôte         127.0.0.1
  Port         5432
  Base         goron_gts
  Utilisateur  goron_gts_app
  Mot de passe dev_app_secret

Tester la connexion, puis Enregistrer.


══════════════════════════════════════
  8. Première connexion
══════════════════════════════════════
  Nom affiché     Admin
  Mot de passe    le GTS_ADMIN_MASTER_CODE de l'étape 4

Admin n'utilise pas un mot de passe « changé dans une modale » : c'est
toujours le fichier acces_admin.env (ou gts-admin.enc).

Badge base vert = environnement prêt.


══════════════════════════════════════
  9. Exploitation courante
══════════════════════════════════════
  Démarrer PG     outils_labo\Lancer-Menu-Labo.bat → 1
  Arrêter PG      même menu → 4
  Logs Docker     même menu → 6
  Journal appli   %APPDATA%\goron-gts\gts-pg-events.log  (menu → 7 / 8)
  Dump labo       même menu → 12  (fichier .dump, pas de rapport HTML)

Sauvegardes applicatives (Paramètres) : fichiers
  goron_gts_journaliere_AAAA-MM-JJ.dump
  goron_gts_mensuelle_AAAA-MM.dump
  goron_gts_manuelle_AAAA-MM-JJ_HH-mm.dump
La comparaison dump / base se fait dans l'application. Aucun rapport HTML
n'est créé après une restauration.

Pare-feu : le labo local n'a pas besoin d'ouvrir 5432 vers le réseau.
Sur un vrai poste serveur LAN, ouvrir TCP 5432 uniquement vers les stations.


══════════════════════════════════════
  10. Repartir à zéro
══════════════════════════════════════
Vider les tables (conteneur conservé) :
  menu labo → touche 11 → taper RESET
  puis relancer Goron GTS (ré-init si demandée).

Recréer un PostgreSQL 100 % neuf :

  docker rm -f goron-pg18
  docker volume rm goron_gts

puis refaire l'étape 5, puis 7 et 8.
Le compte Admin reprend GTS_ADMIN_MASTER_CODE.


══════════════════════════════════════
  11. Dépannage
══════════════════════════════════════
  wsl --install refuse
    → PowerShell bien en administrateur, Windows à jour, reboot

  Docker Desktop bloqué sur « starting »
    → WSL 2 installé, reboot, relancer Docker Desktop

  docker n'est pas reconnu
    → nouveau terminal après installation, ou relogin Windows

  Port 5432 occupé
    → Get-NetTCPConnection -LocalPort 5432
    → arrêter l'autre PostgreSQL Windows

  Badge « Base inaccessible »
    → Docker Engine running, menu labo touche 1 puis 9

  Conteneur introuvable (menu touche 1)
    → refaire le docker run de l'étape 5

  Mot de passe invalide (Admin)
    → fichier étape 4, puis FERMER et relancer Goron GTS
      (le code n'est lu qu'au démarrage)

  Nom affiché inconnu
    → saisir exactement Admin

Ne pas utiliser ce pack comme procédure de production SI.
